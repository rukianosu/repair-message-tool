# 修理完了連絡メッセージ作成ツール

パソコン修理完了時の顧客への連絡メッセージを自動生成するツールです。

---

## 🚀 簡単実行方法（推奨）

**`修理メッセージ作成ツール.html` をダブルクリックするだけ！**

- ブラウザが開いてツールが起動します
- **インストール不要！** Python、Streamlitなどは一切不要
- お客様のPCを汚しません
- どこに置いても動作します（USBメモリでもOK）

---

## ✨ 主な機能

- **運送会社の選択**: ヤマト運輸 / 佐川急便
- **支払い方法の選択**: 銀行振込 / 代引き / 着払い
- **配達時間帯の選択**: 運送会社に応じた時間帯を自動表示
- **送り状番号の入力**: 追跡URLを自動生成
- **修理内容の入力**: 自由記述
- **合計金額の入力**: カンマ区切り対応（例：12,345）
- **配達指定日の設定**: デフォルトは明日の日付
- **ワンクリックコピー**: 完成したメッセージをワンクリックでクリップボードにコピー

---

## 📝 使い方

1. **`修理メッセージ作成ツール.html` をダブルクリック**
2. ブラウザが自動的に開きます
3. 各項目を入力：
   - 運送会社を選択
   - 支払い方法を選択
   - 配達希望時間帯を選択
   - 送り状番号を入力
   - 修理内容を入力
   - 合計金額を入力（カンマ区切りOK）
   - 配達指定日を入力（空欄なら明日）
4. **「📝 メッセージを作成」ボタンをクリック**
5. 完成したメッセージが表示されます
6. **「📋 コピー」ボタンをクリック**でクリップボードにコピー
7. メールやLINEなどに貼り付けて送信

---

## 🔧 メッセージの自動生成内容

生成されるメッセージには以下が含まれます：

- 挨拶文
- 発送日（今日の日付）
- 運送会社の追跡番号と追跡URL
- 修理内容
- 修理代金（支払い方法に応じた表記）
- 配達予定日時
- 確認依頼の文言
- 締めの挨拶

### 支払い方法による表記の違い

- **銀行振込**: 「（消費税込み）」
- **代引き**: 「（代引き手数料および消費税込み）」
- **着払い**: 「（着払い送料・代引き手数料および消費税込み）」
  - 着払いの場合は「修理中断」として返却メッセージになります

## ⚠️ トラブルシューティング

### 問題1: HTMLファイルをダブルクリックしてもブラウザが開かない

**原因**: ファイルの関連付けが正しくない

**解決方法**:
1. HTMLファイルを右クリック
2. 「プログラムから開く」→「別のプログラムを選択」
3. ブラウザ（Chrome、Edge、Firefoxなど）を選択
4. 「常にこのアプリを使って開く」にチェック

### 問題2: コピーボタンが動かない

**原因**: 古いブラウザを使用している

**解決方法**:
- Microsoft Edge、Google Chrome、Firefoxの最新版を使用してください
- コピーボタンが動かない場合は、テキストを手動で選択してコピーしてください
