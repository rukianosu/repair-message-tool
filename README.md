# 修理完了連絡メッセージ作成ツール

パソコン修理完了時の顧客への連絡メッセージを自動生成するツールです。

---

## 🚀 簡単実行方法

**`修理メッセージツール起動.bat` をダブルクリックするだけ！**

- 自動的にブラウザが開いてツールが起動します
- 階層移動やセキュリティ設定の変更は不要です

終了するには、コマンドプロンプトウィンドウを閉じてください。

---

## 📋 事前準備（初回のみ）

### 1. Pythonのインストール

Pythonがインストールされていない場合は、以下からダウンロードしてインストールしてください：
- https://www.python.org/downloads/

### 2. 必要なライブラリのインストール

コマンドプロンプトまたはPowerShellで以下を実行：

```bash
pip install -r requirements.txt
```

または個別にインストール：

```bash
pip install streamlit pyperclip
```

---

## ✨ 主な機能

- **運送会社の選択**: ヤマト運輸 / 佐川急便
- **支払い方法の選択**: 銀行振込 / 代引き / 着払い
- **配達時間帯の選択**: 運送会社に応じた時間帯を自動表示
- **送り状番号の入力**: 追跡URLを自動生成
- **修理内容の入力**: 自由記述
- **合計金額の入力**: カンマ区切り対応（例：12,345）
- **配達指定日の設定**: デフォルトは明日の日付
- **メッセージ自動生成**: すべての情報を含んだ完成メッセージを生成

---

## 📝 使い方

1. **`修理メッセージツール起動.bat` をダブルクリック**
2. ブラウザが自動的に開きます
3. 各項目を入力：
   - 運送会社を選択
   - 支払い方法を選択
   - 配達希望時間帯を選択
   - 送り状番号を入力
   - 修理内容を入力
   - 合計金額を入力（カンマ区切りOK）
   - 配達指定日を入力（空欄なら明日）
4. **「メッセージを作成」ボタンをクリック**
5. 完成したメッセージが表示されるので、コピーして使用

---

## 🔧 メッセージの自動生成内容

生成されるメッセージには以下が含まれます：

- 挨拶文
- 発送日（今日の日付）
- 運送会社の追跡番号と追跡URL
- 修理内容
- 修理代金（支払い方法に応じた表記）
- 配達予定日時
- 確認依頼の文言
- 締めの挨拶

### 支払い方法による表記の違い

- **銀行振込**: 「（消費税込み）」
- **代引き**: 「（代引き手数料および消費税込み）」
- **着払い**: 「（着払い送料・代引き手数料および消費税込み）」
  - 着払いの場合は「修理中断」として返却メッセージになります

## ⚠️ トラブルシューティング

### 問題1: 「streamlitは内部コマンドまたは外部コマンド...として認識されていません」

**原因**: Streamlitがインストールされていない

**解決方法**:
```bash
pip install streamlit
```

### 問題2: バッチファイルをダブルクリックしても何も起きない

**原因**: Pythonがインストールされていない、またはPATHが通っていない

**解決方法**:
1. Pythonを再インストール
2. インストール時に「Add Python to PATH」にチェックを入れる

### 問題3: ブラウザが開かない

**原因**: デフォルトブラウザの設定問題

**解決方法**:
- コマンドプロンプトに表示されるURL（例：http://localhost:8501）を手動でブラウザにコピー
